ALLSELL System Design & Product Architecture

Comprehensive multi-role system specification for Ethiopia's dual-vertical marketplace unifying Houses (Real Estate) and Cars (Automotive) with verified broker KYC, Telebirr lead monetization, and an institutional Government Auditor portal.

Client: Nishank / ALLSELL Team

Platform: Flutter (iOS & Android) + Node.js
Market: Addis Ababa & Regional Ethiopia
1

Executive Summary & Brand Identity

ALLSELL is an end-to-end e-commerce and classifieds marketplace platform tailored specifically for the Ethiopian market. While existing platforms are either informal Telegram channels or single-vertical portals, ALLSELL combines the high discovery speed of Gari / Afrotie with the accessible e-commerce simplicity of Tinamart.

Core Value Proposition: Eradicating counterfeit listings and broker fraud in Ethiopia by enforcing mandatory National ID & TIN verification, issuing cryptographic trust badges, and monetizing buyer inquiries through automated Telebirr and CBE Birr micro-transactions.

The Four Core Business Pillars

The entire platform architecture rests upon four institutional pillars designed for scalability and compliance:

🏡 🚗
1. Unified Dual Marketplace
  • Houses (Villas, Apartments, Condos for Rent & Sale).
  • Cars (Brand New, Ethiopian Used, Foreign Imports).
  • Sub-city location routing (Bole, CMC, Kirkos, Yeka).
  • Instant category tab switcher with zero reload lag.
🛡️ 📜
2. Verified Broker Ecosystem
  • Mandatory KYC: National ID card & TIN Certificate.
  • Business license validation where applicable.
  • Moderator review before issuing the "✓ Verified" mark.
  • Broker performance and lead tracking CRM dashboard.
💳 🔒
3. Transaction & Lead Monitoring
  • Pay-per-contact reveal: Gated behind Telebirr / CBE Birr.
  • Filters out casual window-shoppers & lead scrapers.
  • End-to-end transaction logging (Initiated -> Paid -> Closed).
  • Platform commission split automation.
🏛️ 📊
4. Government & Auditor Portal
  • Unique regulatory portal for Ethiopian Revenue Authority.
  • Real-time gross sales and rental volume tracking (ETB).
  • Automated broker income statements and tax reports.
  • Immutable audit logs for dispute resolution.

User Roles & Access Control Matrix (RBAC)

ALLSELL implements 6 distinct user roles to guarantee data privacy and regulatory separation:

Role Permissions & Scope Monetization & Auth Target Client Surface
Customer Browse, search, filter listings, save favorites, make inquiries, report fake listings. Phone + OTP auth. Pays nominal fee (20 ETB) to view broker contact details. Mobile App (iOS / Android)
Agent / Broker Create & manage house/car listings, view lead inquiries, manage customer CRM, view commission payouts. Full KYC (TIN, National ID, Phone 1 & 2, Photo). Receives verified badge upon approval. Mobile App (Agent Mode) & Broker Web
Moderator Review pending listings, authenticate submitted ownership and TIN documents, approve/reject/suspend. Internal staff auth with multi-factor authentication. Staff Moderator Web Dashboard
Administrator Manage platform categories, system settings, promotional banner slots, commission rates, and dispute resolution. High-security privileged access. Executive Admin Panel
Super Admin Assign admin privileges, trigger database snapshots and system backups, configure payment API credentials. Root system permissions. Master DevOps / Root Console
Auditor / Gov Read-only compliance dashboard: Agent registration statistics, gross sales (ETB), rental turnover, tax withholding statements. Authorized government SSO / Token with audit trail. Dedicated Government / Auditor Portal

Lead Monetization & Telebirr Contact Paywall

In traditional classifieds, phone numbers are scraped and brokers receive endless spam. ALLSELL introduces the Pay-to-Reveal Contact Gate:

sequenceDiagram autonumber actor Buyer as Buyer / User participant App as ALLSELL Mobile participant Pay as Telebirr / CBE Birr participant API as ALLSELL Backend actor Broker as Verified Broker Buyer->>App: Views Listing Details (Photos, Specs, Location) Note over App: Phone number & Email are masked (e.g. +251 91 **** 23) Buyer->>App: Taps "Show Contact" button App->>App: Opens Unlock Modal (e.g., 20 ETB) Buyer->>Pay: Authorizes 20 ETB via Telebirr USSD / QR Pay-->>API: Instant Payment Webhook (Confirmed) API-->>App: Generates Unlock Authorization Token App->>Buyer: Unmasks Phone & Email + Enables 1-Tap Direct Call API->>Broker: Push Alert: "Qualified buyer unlocked your contact info!"
Business Impact: Generates continuous platform revenue on high-frequency buyer intent, ensures only serious buyers reach brokers, and establishes a quantifiable lead conversion pipeline.

Database Models & Entity Architecture

The backend separates real estate domain specifics from vehicle specifics while unifying them under shared transaction, media, and authorization tables: 

// 1. PROPERTIES SCHEMA (Houses & Real Estate)
Table properties {
  id: uuid [pk]
  agent_id: uuid [ref: > users.id]
  listing_type: enum('FOR_SALE', 'FOR_RENT')
  property_type: enum('VILLA', 'APARTMENT', 'CONDOMINIUM', 'COMMERCIAL', 'LAND')
  title: varchar
  price: decimal(14,2)
  currency: varchar(3) // 'ETB'
  region: varchar // 'Addis Ababa'
  sub_city: varchar // 'Bole', 'Kirkos', 'Yeka', etc.
  wereda: varchar
  bedrooms: int
  bathrooms: int
  area_sqm: decimal(8,2)
  furnishing_status: enum('FURNISHED', 'UNFURNISHED', 'SEMI')
  utilities: jsonb // { water: true, backup_generator: true, electricity: true }
  is_verified: boolean
  status: enum('ACTIVE', 'PENDING', 'SOLD', 'RENTED')
}

// 2. VEHICLES SCHEMA (Cars & Automotive)
Table vehicles {
  id: uuid [pk]
  agent_id: uuid [ref: > users.id]
  make: varchar // 'Toyota'
  model: varchar // 'RAV4'
  year: int // 2023
  price: decimal(14,2)
  currency: varchar(3) // 'ETB'
  condition: enum('BRAND_NEW', 'ETHIOPIAN_USED', 'FOREIGN_USED')
  mileage_km: int
  transmission: enum('AUTOMATIC', 'MANUAL')
  fuel_type: enum('PETROL', 'DIESEL', 'ELECTRIC', 'HYBRID')
  body_type: enum('SUV', 'SEDAN', 'PICKUP', 'HATCHBACK')
  is_verified: boolean
  status: enum('ACTIVE', 'PENDING', 'SOLD')
}
